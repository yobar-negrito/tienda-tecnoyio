Requerimientos funcionales

RF1. Registrar productos y pedidos. El sistema debe permitir registrar productos (nombre, categoría, precio, stock) y pedidos (cliente, producto, cantidad, fecha). Antes de guardar, debe validar que los campos obligatorios estén completos y que la cantidad no supere el stock disponible.
RF2. Consultar y actualizar el estado de los pedidos. El sistema debe mostrar el listado de pedidos con su estado (Pendiente, En proceso, Entregado) y permitir cambiarlo.

Requerimiento no funcional

RNF1. Usabilidad. La interfaz debe ser clara y fácil de usar en computador y celular. Debe mostrar mensajes de error junto a cada campo y permitir registrar un pedido en pocos pasos.
